# Post-v1 roadmap suggestions

## Practical v1.x

- Compatibility suite for a selected real OpenAI-compatible provider.
- Additional provider adapter with failure-contract tests.
- Weighted or cost-aware routing only after an explicit policy/evidence design.
- A controlled distributed configuration story and corresponding rollback drill.
- Automated disposable PostgreSQL backup/restore evidence.

## Research / future

- Semantic cache with governance-safe invalidation.
- Adaptive routing with explicit quality, latency, and cost evaluation.

These are suggestions, not opened issues and not prerequisites for the RC.
