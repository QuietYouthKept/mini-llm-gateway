## Review finding fixed in this workspace

A reservation lease used to be fixed at 30 seconds while request timeout is
configurable. A sufficiently long request could be reclaimed by maintenance
before it settled. The lease is now derived as at least the request deadline
plus a five-second wall-clock buffer (and at least 30 seconds); expired leases
also refuse settlement atomically. Regression: `test_expired_reservation_cannot_settle_before_maintenance_runs`.
