# v1.0.0-rc1 release notes

## Highlights

1. Failure-tested routing, retry, fallback, and circuit protection.
2. Distributed governance with Redis global rate limit, cache, and singleflight.
3. Transactional token budgets with durable reservation lifecycle.
4. Explainable decision traces, scoped audit retrieval, and offline replay.
5. Reproducible local evidence, demos, evaluations, and release material.

## Added

- Redis owner-token lease with TTL and safe Lua unlock for global cache-miss
  coalescing.
- PostgreSQL reservation lease migration and an admin-only reconciliation action.
- Prometheus alert examples, ingress TLS boundary example, and RC release docs.

## Changed

- Redis rate limiting fails closed by default; cache and singleflight degrade
  without hanging when Redis is unavailable.
- Offline replay remains side-effect-free unless live replay is explicitly enabled.
- The release candidate version is `1.0.0rc1` in package and FastAPI metadata.

## Fixed

- Cache output is governed before publication.
- Budget admission is a reservation rather than a check-then-increment race.
- Audit request and provider-attempt writes are transactional and client scoped.
- Reload avoids stale compatible state; reservation cancellation paths release.
- Reservation lease now exceeds the configured request deadline.

## Known limitations

This is a manual-review candidate, not a production certification. Real paid
providers, cloud HA, production certificates/secrets, backup operation, and
multi-day soak remain unverified.
