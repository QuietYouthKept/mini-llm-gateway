\# Mini LLM Gateway



A local-first LLM Gateway demo that demonstrates routing, fallback, rate limiting, budget control, request logging, and mock provider governance.



\## Current Status



Skeleton stage.



\## Why this project exists



Model calls should not be scattered across business code. This project explores how an LLM Gateway can centralize provider routing, fallback, limits, budgets, and request audit logs.
